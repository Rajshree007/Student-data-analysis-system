# Student-data-analysis-system

# 📚 Attendance & Student Analytics System (Flask + ML)

A web-based platform for managing student attendance, predicting academic performance using ML, analyzing attendance trends, forecasting dropout rates, and generating personalized study plans.

---

## 🔧 Tech Stack

- **Frontend**: HTML, CSS, JS (Basic UI)
- **Backend**: Flask (Python)
- **Database**: MySQL (via `mysql-connector-python`)
- **Machine Learning**: scikit-learn
- **Visualization**: Matplotlib
- **Speech Recognition**: SpeechRecognition + Pyttsx3 (for voice-based attendance)

---

## 🚀 Key Features

### 👥 Roles
- **Administrator**
  - Upload student Excel data
  - Manage attendance tables per semester/division
  - Configure maximum allowed admissions for dropout forecasting
- **Teacher**
  - Take attendance (manually or via speech)
  - View/download attendance records
  - Analyze attendance via pie/bar graphs
  - Group students based on marks/SPI
  - Forecast dropout trends per branch
- **Student**
  - Predict result & SPI using mid-sem marks
  - Visualize personal attendance
  - Generate a personalized study planner
